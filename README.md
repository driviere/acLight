# Bakery Ledger

An accounting web application designed specifically for a bakery, developed using a "user-simple but accounting-rigorous" philosophy.

## Tech Stack
- Frontend: React (SPA)
- Styling: Bulma CSS
- Icons: Solar Icon Set
- Backend: Firebase (Auth, Firestore)

## Features
- Double-Entry Bookkeeping hidden behind simple actions.
- Cents-Only Integer Logic for zero floating-point errors.
- Role-Based Access Control (Admin vs Staff).
